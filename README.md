sovinc

A Next.js web3 design application.

## Getting Started

```bash
npm run dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

For deployment instructions, see [DEPLOYMENT.md](./DEPLOYMENT.md).
